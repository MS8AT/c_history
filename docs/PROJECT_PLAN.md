# Target и план проекта c_history

## Target

Создать отдельный публичный проект `c_history`: красивую адаптивную
веб-историю с фирменным знаком WorkBooth, которая в форме современной сказки
рассказывает о компании, внимательном AI-контуре и Dashboard, но намеренно не
раскрывает внутренние технические подробности.

## Критерии готовности

1. История читается как цельное художественное произведение на русском языке.
2. Фирменный знак WorkBooth присутствует и не изменён.
3. AI-контур и Dashboard показаны как концептуальные образы.
4. Страница работает локально без сборки, зависимостей и внешней сети.
5. Desktop и mobile layouts остаются читаемыми; клавиатурный фокус и режим
   reduced motion поддержаны.
6. В публичном пакете нет секретов, адресов, конфигураций, данных, внутренних
   маршрутов, operational screenshots или заявлений о конкретном deployment.
7. Автоматическая проверка завершается PASS.
8. Локальный Git commit, публичная видимость GitHub и совпадение remote HEAD с
   локальным commit подтверждены раздельно.

## Ограничения

- Только новая папка `c_history`; Dashboard, API, firmware и AI runtime не
  изменяются.
- Никаких внешних CDN, шрифтов, аналитики, трекеров или API.
- Никаких непроверенных чисел, обещаний эффективности или статуса production.
- Публикация выполняется только в отдельный репозиторий `MS8AT/c_history`.
- Публичность относится только к содержимому этого пакета.

## План работы

1. Проверить правила workspace, структуру, существующие изменения и бренд.
2. Зафиксировать public-safe границу и состав проекта.
3. Создать narrative, layout, локальные artwork/assets и документацию.
4. Добавить автономный validator.
5. Выполнить deterministic, security и visual проверки.
6. Получить независимый Supervisor review.
7. Создать локальную Git-историю в `c_history`.
8. Создать публичный GitHub-репозиторий, push и выполнить read-back проверку.

## Затрагиваемые компоненты

- статическая страница: `index.html`, `styles.css`, `script.js`;
- публичные assets: `assets/`;
- документация: `README.md`, `LICENSE.md`, `docs/`;
- проверка: `tests/validate-project.mjs`, `package.json`;
- правила проекта: `AGENTS.md`, `.gitignore`.

Существующий продуктовый код не входит в scope.
