# c_history contributor notes

`c_history` is a public, standalone story about WorkBooth. Keep it suitable for
an unauthenticated public audience.

## Boundaries

- Tell the story at a conceptual level only.
- Do not add endpoints, addresses, credentials, customer data, internal names,
  source excerpts, operational screenshots, model identities or deployment
  claims.
- Keep the site dependency-free and functional offline.
- Reuse the supplied WorkBooth mark unchanged. New decorative artwork must be
  original and stored locally.
- Treat AI and Dashboard scenes as artistic metaphors, not architecture docs.

## Checks

Run `npm test` before publication. Also review the page at desktop and narrow
mobile widths, with keyboard navigation and reduced-motion enabled.
